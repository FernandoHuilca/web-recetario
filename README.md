**La Cocina de Gregory** es una aplicación web robusta para la gestión y visualización de recetas culinarias. Este proyecto fue desarrollado aplicando patrones de diseño empresarial como **MVC (Modelo-Vista-Controlador)** y **DAO (Data Access Object)**, asegurando una arquitectura limpia y escalable. 

El sistema permite a los usuarios explorar un catálogo de recetas, gestionar sus propias creaciones y guardar sus favoritas, todo construido sobre tecnologías **Java Enterprise (Jakarta EE)**, **JPA** y una base de datos **MySQL**. 🥘🥗

## Características del Proyecto

La aplicación ofrece una experiencia fluida para los amantes de la cocina, permitiendo centralizar el conocimiento culinario en una plataforma digital moderna.


El núcleo del sistema permite una manipulación completa de los datos:
- **Visualización Detallada:** Fichas completas con ingredientes, pasos de preparación, tiempos y porciones.
- **Sistema de Favoritos:** Funcionalidad para marcar y guardar recetas preferidas para un acceso rápido.

## Arquitectura del Software

El proyecto sigue estrictamente el patrón **MVC**:
- **Modelo:** Entidades (`Receta`, `Ingrediente`, `Usuario`) y DAOs para la lógica de negocio y acceso a datos.
- **Vista:** Páginas **JSP** con **JSTL** y **CSS personalizado** para una interfaz limpia y responsive.
- **Controlador:** **Servlets** que actúan como `FrontController`, despachando las peticiones y gestionando el flujo de la aplicación.

## Tecnologías Utilizadas 🛠 

El stack tecnológico seleccionado garantiza rendimiento y mantenibilidad:

- **Lenguaje:** Java (JDK 17+)
- **Web Framework:** Jakarta EE (Servlets, JSP, JSTL)
- **Base de Datos:** MySQL
- **ORM / Persistencia:** JPA (EclipseLink)
- **Frontend:** HTML5, CSS3 (Framework propio), JavaScript
- **Servidor de Aplicaciones:** Apache Tomcat 10
- **IDE:** Eclipse Enterprise
